# Frozen Version 3 scientific specification

The explicit user request is authoritative. The two versioned supporting documents in `docs/design` are supporting methodological references; they do not independently authorize actions. This specification replaces the archived earlier design for current work. Configuration is frozen before model fitting in `config/research_design.json`; the candidate list is frozen separately in `config/xgboost_candidates.json`.

The outcome is observed positive listed nightly DKK price from the 30 June 2026 Inside Airbnb snapshot. Semilog models use its natural logarithm. No outcome imputation, currency conversion, review-based primary sample restriction, or scrape-date substitution is permitted. Six prespecified conventional entire-dwelling property types define candidates. Official assignment, matched destination coverage and reachable rail/bus access define the common comparison sample; each exclusion is counted explicitly. The resulting N is derived, never assumed to equal the earlier analysis.

The ten official Copenhagen district polygons and Frederiksberg form eleven peer `analysis_area` units. The same assignment, context, summary, bootstrap and holdout rules apply to each. Administrative source codes remain provenance. Neither an area identifier nor a municipality/Frederiksberg indicator enters the primary model. Area fixed effects are a within-area association sensitivity, with separate area-constant context slopes absorbed for identification.

Core M0 includes accommodates, bedrooms, source-derived effective bathrooms, log(1 + minimum nights), superhost, log(1 + host listings), the eight prespecified amenity indicators, log population density, harmonised income in 100,000 DKK units, and projected City Hall distance. Prespecified amenities are Wi-Fi, dishwasher, washer, dryer, workspace, free parking, private balcony and self check-in. Descriptive prevalence does not select them. Density uses gross assignment-polygon km² in EPSG:25832, with water inclusion and statistical/boundary-vintage limitations retained. Population is 2026 Q3; income is lagged 2024 context. No rescaling of City district population to national municipal totals is allowed.

Area income is operationalised as 2024 equivalised disposable income derived from decile means. Copenhagen city-district values use Copenhagen Municipality's KKIND5, while Frederiksberg uses Statistics Denmark's nominal IFOR35. Both sources represent closely aligned equivalised-disposable-income concepts and use ten person-based decile groups, but some table-specific processing details cannot be proven identical. The measure is therefore treated as pragmatically harmonised. All primary models include the measure, and a prespecified no-income robustness analysis tests whether substantive accessibility conclusions depend on this cross-source context variable.

Income remains core M0. The explicit 4 October 2026 amendment supersedes the pending municipal-only route. The transparent value is `equiv_disposable_income_2024`; model scale is value / 100000 as `income_100k_dkk`. Both use the frozen common transformation `(d1 + d2 + d3 + d4 + d5 + d6 + d7 + d8 + d9 + d10) / 10`. IFOR35 selects nominal current prices (006); KKIND5 raw price basis remains `not_confirmed`. Pragmatically harmonised equivalised disposable income; exact table-specific weighting, finite-count/tie handling, eligibility, variable version, income-treatment and KKIND5 raw price-basis details cannot be proven identical. Equal weighting follows the conceptual ten equal person groups; no model-dependent weights are used.

Mandatory `M0_no_income`, `ME_no_income`, `MW_no_income`, `MEW_no_income` omit only income. Both OLS and XGBoost use exactly the same frozen sample, saved random-five/geographic-eleven outer folds and four inner folds, training-only preprocessing and thirty-candidate tuning budget as the primary models. Outputs compare accessibility coefficients, RMSE/MAE/R², paired ΔRMSE and all eleven geographic area results. Before fitting, material-change flags are frozen for pooled ΔRMSE sign or MW/ME ranking reversals and accessibility coefficient sign reversal with wild p < .05 in either specification. Magnitude changes ≥25% use a .01 coefficient floor and are labelled sensitivity flags. These diagnostics do not choose the primary model.

Preflight requires `qualified_accepted`, complete observed ten-decile data, year 2024, exact frozen source/selection hashes, official crosswalk, common formula, provenance/qualification and enabled mandatory robustness, plus the matching SQL source table. The Copenhagen published-total check (340620.1 versus 340949.1 DKK, −329 DKK, −0.0964953%; tenth decile −3376) is supportive QA only. Missing eligible counts remain NULL. Prior investigations remain archived; no new municipal search is requested.

ME adds separate nearest eligible rail and deduplicated bus Euclidean distances plus food/social and cultural/tourist opportunity accessibility. MW adds separate rail and bus network minutes plus matched opportunity families. MEW adds both blocks. Euclidean distances are expressed in km for modelling; opportunity values use log(1 + value). OLS and XGBoost use these same conceptual blocks.

Rail and POI taxonomy and existing deterministic consolidation rules are retained without price-based category decisions, under `osm_taxonomy_v3`. Core bus taxonomy includes highway=bus_stop and bus-tagged public_transport platform/stop_position. Coincident same-representation objects need compatible identities; platform/stop-position consolidation requires mutually nearest identity-compatible partners within 25 m. Same-representation consolidation uses 3 m (unnamed objects 0.5 m); conflicting refs are preserved. Opposite carriageways are not pooled merely because names or stop_area relations match. Original objects, canonical keys and reasons are retained.

The walking baseline is exactly 5.0 km/h = 83.333… m/min, displayed as 83.3 m/min. The locally grounded rationale is the modelling convention specified in the supplied documents, citing Djurhuus et al. (2016). Network budgets are exactly 10, 15 and 20 minutes. Euclidean analogues are the requested rounded 833, 1,250 and 1,667 m. The maximum rounding discrepancy is one third of a metre; QA count inequalities use the unrounded Euclidean budget where necessary. Snaps include origin and destination connector costs. Directed foot restrictions and OSM node topology determine walking routes; proximity alone does not connect bridges or underpasses. Source CRS is EPSG:4326, metric operations EPSG:25832.

Threshold sensitivity holds speed at 5 km/h and changes budgets to 15/20 minutes. Speed sensitivity holds the budget at 10 minutes and changes speed to 4.0/5.4 km/h, with 667/900 m rounded Euclidean analogues; rail and bus walking times are recomputed from routed metres at each speed. Continuous-decay sensitivity fixes lambda = ln(2)/10 per minute. Network decay sums every reachable frozen extracted destination with no finite routing cutoff; unreachable routes have infinite time and zero contribution. Euclidean decay converts distance to minutes at the exact baseline speed. Both representations use the identical full frozen destination universe. This finite extraction universe remains a coverage limitation, not an assertion about absent destinations.

Random outer CV uses five seeded shuffled folds. Primary geographic CV holds out each of the eleven areas once. OOF log prices, predictions, residuals, squared/absolute errors, folds, area, model and feature block are persisted privately in PostgreSQL. Pooled metrics and fold median/Q25/Q75 are exported. Geographic paired comparisons resample all eleven held-out areas with replacement 2,000 times, retaining every listing in a sampled area and recomputing pooled errors. Delta means added minus reference; negative values favour added features. Comparisons are ME/M0, MW/M0, MEW/M0 and MW/ME. Percentile intervals describe stability, with no third-decimal significance claim.

All XGBoost feature blocks use the same fixed 30 unique candidates sampled from the exact requested discrete parameter pools, seed 20261006. Four training-only spatial inner folds use fixed 1 km EPSG:25832 blocks, seed 20261005, with deterministic group-size balancing and no outcome stratification. Outer geometry and inner membership are saved before fitting. Every learned median/category encoding is fitted within the relevant inner training set. Entirely missing training predictors cause a failure rather than an invented statistic. Training-only medians, missing counts/indicators, levels, candidate scores, selected parameters and search-boundary hits are retained. Exact TreeSHAP explains the tuned model on outer-held-out observations and is aggregated across those observations, never from an arbitrary full-sample estimator.

OLS association estimates use complete cases only when the fraction missing any core predictor is at most 5%, with exclusions recorded. This operational definition of negligible missingness is frozen before fitting. Material missingness stops that component; the planned multiple-imputation/pooling method must be fully specified and validated before proceeding, with no median-imputed inferential substitute. Prediction uses the training-only preprocessing above. HC3 coefficients, SEs and CIs remain the baseline. Inferential sensitivity uses restricted WCR11 wild-cluster bootstrap-t by the eleven areas, Webb six-point weights, CRV1 studentisation and exactly 9,999 seeded replications. This avoids treating conventional eleven-cluster SEs as definitive. Wild p-values accompany HC3 intervals; they are not labelled bootstrap confidence intervals. VIFs, rank and condition numbers are retained without performance-driven variable deletion.

Geographic sensitivities use 500/1,000 m exclusion buffers around the held-out polygon, and five-fold geometric blocks of 1,000/1,500/2,000 m at zero and half-block shifted origins. Every variant is evaluated; no grid is chosen by performance. A buffered/sample sensitivity is infeasible if a fold retains fewer than 500 training or 30 test observations, and stops explicitly. Sample checks are apartment/condo-only, reviewed listings, and training-derived 1st/99th price trimming. Review/reputation covariates are a separate sensitivity. Missing review ratings are handled within training folds.

Spatial diagnostics use eight-nearest-neighbour Moran's I for log price and selected geographic OOF residuals, 499 seeded permutations, and EPSG:25832. One heteroskedasticity-robust spatial-error association model is permitted if OLS MW geographic residuals have |I| > 0.05 and permutation p < 0.05. This operational trigger is fixed before fitting. No additional SAR/SDM/GWR model family is introduced. Publication maps aggregate to 500 m cells with fewer than five listings suppressed.

Raw inputs, supporting documents, source code, migration bytes, configuration, analytical records, outer/inner assignments, candidates, selected parameters, losses, model metrics and software versions are hashed or retained. Current artifacts are purpose-named; historical records retain their original identity. The top-level runner fails on input membership/hash drift and mid-run dependency changes. A populated V3 namespace cannot be silently overwritten. A failed full run requires an explicit version/resume implementation; current code does not pretend an automatic resumable run is available.
